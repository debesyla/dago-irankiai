Tikslumas ir išimtys

Įrankis naudoja patikrintų vardų sąrašą, dažniausias galūnių taisykles ir žinomas išimtis. Reti, užsienietiški, sudurtiniai ar neatpažinti vardai gali būti palikti nepakeisti arba pažymėti „Patikrinkite“. Konkretaus tikslumo procento nežadame — prieš siųsdami žinutę peržiūrėkite pažymėtas formas ir prireikus jas pataisykite.

Saugus atsarginis kreipinys

Jei forma abejotina ir negalite jos patikrinti, vardo nenaudokite. Saugus neutralus variantas: „Laba diena,“. Jis patikimesnis už netaisyklingą asmeninį kreipinį.

Privatumas

Įvesti vardai ir rankiniai pataisymai apdorojami tik šiame naršyklės lange. Jie nesiunčiami į serverį ir neišsaugomi. Uždarius ar atnaujinus puslapį rezultatai dingsta.

Kodo pavyzdžiai

LLM / AI

Vietaženklį pakeiskite savo vardų sąrašu.

Užduotis: paversk žemiau pateiktus vardus į lietuvių kalbos šauksmininką.

Šauksmininkas – linksnis, vartojamas tiesiogiai kreipiantis į žmogų. Pavyzdžiui, vardininkas „Jonas“ sakinyje „Jonas atėjo“ tampa šauksmininku „Jonai“ kreipinyje „Labas, Jonai!“.

Dažniausi pavyzdžiai:
Jonas → Jonai
Eglė → Egle
Saulius → Sauliau
Jurgis → Jurgi
Stasys → Stasy

Taisyklės:
1. Išlaikyk vardų eilės tvarką.
2. Kiekvieną vardą grąžink atskiroje eilutėje.
3. Išlaikyk originalų didžiųjų ir mažųjų raidžių formatą.
4. Atsakyme pateik tik pakeistus vardus – be numeracijos ir paaiškinimų.
5. Jei vardas užsienietiškas, retas, sudurtinis arba forma neaiški, nespėliok: palik jį nepakeistą ir pridėk „[patikrinti]“.

Vardai:
[ČIA ĮKLIJUOKITE VARDUS – PO VIENĄ EILUTĖJE]

JavaScript 
function iSauksmininka(vardas) {
    const taisykles = [
        ['ius', 'iau'],
        ['ys', 'y'],
        ['as', 'ai'],
        ['is', 'i'],
        ['us', 'au'],
        ['ė', 'e'],
    ];

    const taisykle = taisykles.find(function ([galune]) {
        return vardas.endsWith(galune);
    });

    if (!taisykle) return vardas;

    const [galune, pakaitalas] = taisykle;
    return vardas.slice(0, -galune.length) + pakaitalas;
}

['Jonas', 'Eglė', 'Saulius'].map(iSauksmininka);
// ['Jonai', 'Egle', 'Sauliau']
PHP 
<?php

function iSauksmininka(string $vardas): string
{
    $taisykles = [
        'ius' => 'iau',
        'ys' => 'y',
        'as' => 'ai',
        'is' => 'i',
        'us' => 'au',
        'ė' => 'e',
    ];

    foreach ($taisykles as $galune => $pakaitalas) {
        if (str_ends_with($vardas, $galune)) {
            return mb_substr($vardas, 0, -mb_strlen($galune)) . $pakaitalas;
        }
    }

    return $vardas;
}

$vardai = ['Jonas', 'Eglė', 'Saulius'];
$sauksmininkai = array_map('iSauksmininka', $vardai);
// ['Jonai', 'Egle', 'Sauliau']
