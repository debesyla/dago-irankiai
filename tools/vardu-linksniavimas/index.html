Naudojimas naujienlaiškiuose

MailerLite
  1. Atverkite „Subscribers → Fields“, sukurkite teksto lauką „Kreipinys“ ir pasižiūrėkite, kokią žymą jam suteikė MailerLite.
  2. Pasirinkite „Subscribers → Add subscribers“, importuokite atsisiųstą CSV ir stulpelį KREIPINYS susiekite su nauju lauku.
  3. Jei lauko žyma yra kreipinys, šablone naudokite Laba diena, {$kreipinys|default('')}. Prieš siųsdami patikrinkite laišką su tikro gavėjo duomenimis.

Oficialios MailerLite importo gairės · kintamųjų gairės

Omnisend
  1. Atverkite „Audience → Contacts → Add or update contacts“ ir pasirinkite kontaktų importą iš failo.
  2. „Map Properties“ žingsnyje stulpelį KREIPINYS susiekite su nauja „Custom Property“ tipo savybe KREIPINYS.
  3. Šablone naudokite Laba diena, [[contact.custom_properties.KREIPINYS | default: ""]]. Personalizaciją peržiūrėkite pasirinkę tikrą kontaktą.

Oficialios Omnisend importo gairės · personalizavimo gairės

Mailchimp
  1. Auditorijos nustatymuose sukurkite teksto lauką „Kreipinys“ ir priskirkite jam trumpą žymą, pavyzdžiui, KREIP.
  2. Importuokite atsisiųstą CSV ir stulpelį KREIPINYS susiekite su šiuo auditorijos lauku.
  3. Laiške naudokite Laba diena, *|KREIP|*! ir prieš siųsdami patikrinkite peržiūrą su tikro gavėjo duomenimis.

Oficialios Mailchimp CSV gairės

Brevo
  1. Importuokite CSV į kontaktų sąrašą.
  2. Susiejimo žingsnyje KREIPINYS priskirkite naujam arba esamam teksto tipo kontakto atributui tokiu pačiu pavadinimu.
  3. Šablone įterpkite Laba diena, {{ contact.KREIPINYS }}!. Tuščiai reikšmei Brevo redaktoriuje nustatykite neutralų atsarginį tekstą.

Oficialios Brevo importo gairės

Klaviyo
  1. Atverkite „Audience → Lists & Segments“, pasirinkite sąrašą ir importuokite atsisiųstą CSV.
  2. Stulpelį KREIPINYS susiekite su nauja teksto tipo profilio savybe KREIPINYS.
  3. Šablone naudokite Laba diena, {{ person.KREIPINYS }}! arba įterpkite savybę per „Personalization“ meniu.

Kodo pavyzdžiai

LLM / AI

Vietaženklį pakeiskite savo vardų sąrašu.

Užduotis: paversk žemiau pateiktus vardus į lietuvių kalbos šauksmininką.

Šauksmininkas – linksnis, vartojamas tiesiogiai kreipiantis į žmogų. Pavyzdžiui, vardininkas „Jonas“ sakinyje „Jonas atėjo“ tampa šauksmininku „Jonai“ kreipinyje „Labas, Jonai!“.

Dažniausi pavyzdžiai:
Jonas → Jonai
Eglė → Egle
Saulius → Sauliau
Jurgis → Jurgi
Stasys → Stasy

Taisyklės:
1. Išlaikyk vardų eilės tvarką.
2. Kiekvieną vardą grąžink atskiroje eilutėje.
3. Išlaikyk originalų didžiųjų ir mažųjų raidžių formatą.
4. Atsakyme pateik tik pakeistus vardus – be numeracijos ir paaiškinimų.
5. Jei vardas užsienietiškas, retas, sudurtinis arba forma neaiški, nespėliok: palik jį nepakeistą ir pridėk „[patikrinti]“.

Vardai:
[ČIA ĮKLIJUOKITE VARDUS – PO VIENĄ EILUTĖJE]

JavaScript 
function iSauksmininka(vardas) {
    const taisykles = [
        ['ius', 'iau'],
        ['ys', 'y'],
        ['as', 'ai'],
        ['is', 'i'],
        ['us', 'au'],
        ['ė', 'e'],
    ];

    const taisykle = taisykles.find(function ([galune]) {
        return vardas.endsWith(galune);
    });

    if (!taisykle) return vardas;

    const [galune, pakaitalas] = taisykle;
    return vardas.slice(0, -galune.length) + pakaitalas;
}

['Jonas', 'Eglė', 'Saulius'].map(iSauksmininka);
// ['Jonai', 'Egle', 'Sauliau']
PHP 
<?php

function iSauksmininka(string $vardas): string
{
    $taisykles = [
        'ius' => 'iau',
        'ys' => 'y',
        'as' => 'ai',
        'is' => 'i',
        'us' => 'au',
        'ė' => 'e',
    ];

    foreach ($taisykles as $galune => $pakaitalas) {
        if (str_ends_with($vardas, $galune)) {
            return mb_substr($vardas, 0, -mb_strlen($galune)) . $pakaitalas;
        }
    }

    return $vardas;
}

$vardai = ['Jonas', 'Eglė', 'Saulius'];
$sauksmininkai = array_map('iSauksmininka', $vardai);
// ['Jonai', 'Egle', 'Sauliau']
