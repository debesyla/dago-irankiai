testiniai žmonės // dago

Reikia žmogaus formai, maketui ar programos testui? Vienas paspaudimas – ir turite išgalvotus duomenis.

← Visi įrankiai

Viskas generuojama jūsų naršyklėje. Vardai gali sutapti su tikrais, tačiau duomenys nesusieti su jokiu tikru žmogumi. Adresas, telefonas ir pašto kodas – testiniai.

Peržiūrėti JSON

Kas sugeneruojama?

Vardas, pavardė, lytis, gimimo data, amžius (18–80 metų), adresas Lietuvoje, el. paštas, testinis telefonas, profesija, įmonė ir ID su TEST- pradžia.

ID nėra asmens kodas. Jei testuojate asmens kodo tikrinimą, naudokite asmens kodų įrankį. El. paštas naudoja example.com; telefonas ir LT-00000 netinka realių kontaktų ar adresų validavimui.

LLM ir kitoms programoms

Duomenis galima pasiimti tiesiogiai arba naudoti tą patį generatorių savo projekte. Be registracijos ir API rakto.

Gauti JSON iš šio puslapio

Vienas žmogus (JSON) · 100 žmonių (JSON) · Instrukcijos LLM

Tai pastovūs v1 pavyzdžiai, ne dinaminis API. Amžius apskaičiuotas 2026-01-01 dienai; kiekvienas įrašas turi referenceDate. Pakartotinės užklausos grąžina tuos pačius duomenis.

curl https://dago.lt/irankiai/testiniai-zmones/person.v1.json
const people = await fetch(
  'https://dago.lt/irankiai/testiniai-zmones/people.v1.json'
).then(response => {
  if (!response.ok) throw new Error('Nepavyko gauti duomenų');
  return response.json();
});
Generuoti savo programoje (JavaScript / Node.js)

Atsisiųskite generator.v1.mjs ir importuokite savo projekte. Priklausomybių nereikia. Ta pati seed, referenceDate ir generatoriaus versija duoda tą patį rezultatą.

import { generatePeople } from './generator.v1.mjs';

const people = generatePeople({
  count: 10,                 // nuo 1 iki 1000
  seed: 'mano-testas',       // praleidus – atsitiktinis rinkinys
  referenceDate: '2026-01-01' // praleidus – šiandien (UTC)
});
console.log(JSON.stringify(people, null, 2));

Galima importuoti tiesiogiai ir naršyklėje:

import { generatePerson } from
  'https://dago.lt/irankiai/testiniai-zmones/src/generator.v1.mjs';

console.log(generatePerson());

ID skirtas testavimui; garantuoto unikalumo ir kriptografinio atsitiktinumo nežadame. Vienodi nustatymai atkuria vienodus ID.

Promptas: pasiimti duomenis su LLM 
Man reikia fiktyvių lietuviškų žmonių duomenų programos testavimui.
Perskaityk https://dago.lt/irankiai/testiniai-zmones/llms.txt.
Paimk https://dago.lt/irankiai/testiniai-zmones/people.v1.json ir grąžink pirmus 5 įrašus kaip JSON masyvą, nekeisdamas laukų ar reikšmių.
Tai pastovus v1 rinkinys, ne naujai sugeneruoti duomenys. Išlaikyk referenceDate ir isTestData.
Jei negali atverti nuorodų, pasakyk tai; netvirtink, kad gavai duomenis.
Promptas: sukurti savo generatorių 
Sukurk fiktyvių lietuviškų žmonių generatorių mano projekte.
Grąžink JSON su schemaVersion: 1, isTestData: true, referenceDate,
id (TEST- pradžia), firstName, lastName, fullName, gender, birthDate
(YYYY-MM-DD), age, email, phone, address (street, city, postalCode,
country, countryCode), occupation ir company.
Naudok lietuviškus vardus ir su jais suderintas pavardes.
Amžius turi būti 18–80 metų ir tiksliai atitikti gimimo datą bei referenceDate.
Duomenys turi būti išgalvoti. El. paštui naudok example.com,
telefonui +370 000 XXXXX, pašto kodui LT-00000, adresui testines gatves.
Negeneruok tikro asmens kodo. Palaikyk count (1–1000), seed ir
referenceDate: tie patys nustatymai turi atkurti tą patį rinkinį.
Pridėk gimimo datos, amžiaus, pakartojamumo ir netinkamų įvesčių testus.
