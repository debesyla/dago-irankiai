Kas sugeneruojama?

Vardas, pavardė, lytis, gimimo data, amžius (18–80 metų), adresas Lietuvoje, el. paštas, lietuviško formato telefonas, profesija, įmonė ir asmens kodas. Išskleidę papildomas skiltis rasite paskyros duomenis, fizines savybes, vietą, transportą ir Stripe testinę kortelę.

Asmens kodo gimimo data ir lytis sutampa su žmogaus duomenimis, kontrolinis skaitmuo apskaičiuojamas ta pačia logika kaip asmens kodų įrankyje. Telefonas pateikiamas tarptautiniu formatu +3706XXXXXXX. El. paštas naudoja example.com.

Adresai ir validatorių tikrinimas

Gatvė, namo numeris, miestas ir pašto kodas parenkami kartu iš 7 patikrintų viešų įstaigų adresų. Namo ar buto numeris nekeičiamas. Tai ribotas sąrašas, ne visas Lietuvos adresų registras; adresai gali kartotis.

Asmens kodai praeina struktūros ir kontrolinio skaitmens patikrą, telefonai – Lietuvos mobiliojo numerio formato patikrą. Tapatybės patvirtinimas, SMS patvirtinimas ar konkrečios išorinės adresų bazės patikra nėra garantuojami. Sugeneruoti numeriai ir kodai gali sutapti su tikrais; naudokite tik testavimui, nesiųskite SMS ir neskambinkite.

LLM ir kitoms programoms

Duomenis galima pasiimti tiesiogiai arba naudoti tą patį generatorių savo projekte. Be registracijos ir API rakto.

Gauti JSON iš šio puslapio

Vienas žmogus (JSON) · Instrukcijos LLM

Tai pastovūs v3 pavyzdžiai, ne dinaminis API. Amžius apskaičiuotas 2026-01-01 dienai; kiekvienas įrašas turi referenceDate. Pakartotinės užklausos grąžina tuos pačius duomenis.

curl https://dago.lt/irankiai/testiniai-zmones/person.v3.json
const person = await fetch(
  'https://dago.lt/irankiai/testiniai-zmones/person.v3.json'
).then(response => {
  if (!response.ok) throw new Error('Nepavyko gauti duomenų');
  return response.json();
});
Generuoti savo programoje (JavaScript / Node.js)

Atsisiųskite generator.v3.mjs ir importuokite savo projekte. Priklausomybių nereikia. Ta pati seed, referenceDate ir generatoriaus versija duoda tą patį rezultatą.

import { generatePerson } from './generator.v3.mjs';

const person = generatePerson({
  seed: 'mano-testas',       // praleidus – atsitiktinis rinkinys
  referenceDate: '2026-01-01' // praleidus – šiandien (UTC)
});
console.log(JSON.stringify(person, null, 2));

Galima importuoti tiesiogiai ir naršyklėje:

import { generatePerson } from
  'https://dago.lt/irankiai/testiniai-zmones/src/generator.v3.mjs';

console.log(generatePerson());

Duomenys skirti testavimui. Garantuoto asmens kodų unikalumo nežadame; vienodi nustatymai atkuria vienodus duomenis.

Promptas: pasiimti duomenis su LLM 
Man reikia fiktyvių lietuviškų žmonių duomenų programos testavimui.
Perskaityk https://dago.lt/irankiai/testiniai-zmones/llms.txt.
Paimk https://dago.lt/irankiai/testiniai-zmones/person.v3.json ir grąžink žmogų kaip JSON objektą, nekeisdamas laukų ar reikšmių.
Tai pastovus v3 rinkinys, ne naujai sugeneruoti duomenys. Išlaikyk referenceDate ir isTestData.
Jei negali atverti nuorodų, pasakyk tai; netvirtink, kad gavai duomenis.
